以下配置项用于控制部署行为，修改后需重新部署才能生效。

自动压缩资源

上传时自动压缩 HTML/CSS/JS 文件

启用 CDN 加速

通过全球节点分发静态资源

强制 HTTPS

所有访问自动跳转到安全连接

访问密码保护

为站点添加简单的密码访问限制

保留历史版本

每次部署保留旧版本，支持回滚

通常上传完成后 3-5 秒内即可访问。如果使用了 CDN 加速，全球节点同步可能需要 10-30 秒。首次访问可能会稍慢，之后会从边缘节点快速返回。
支持所有静态文件：HTML、CSS、JavaScript、图片（PNG/JPG/SVG/WebP）、字体、JSON、XML 等。不支持服务端脚本（如 PHP、Python），因为这是纯静态托管服务。
项目名称只能包含小写字母、数字和短横线（-），长度 2-63 个字符。名称必须唯一，不能与已有项目重复。建议使用有意义的英文名称，如 my-portfolio。
重新上传相同项目名称的文件即可覆盖旧版本。系统会自动保留最近 3 个历史版本（如果开启了版本保留功能），你可以随时回滚到之前的版本。
免费账户每月有 100GB 流量和 100 万次请求额度，对于个人项目和小型展示站点完全够用。超出后可以升级到付费计划，或者等待下月额度重置。
测试提示：此页面包含大量 CSS 动画、外部字体和图标库。如果部署后所有样式正常显示、动画流畅运行，说明静态资源加载和 CDN 配置均正常工作。
